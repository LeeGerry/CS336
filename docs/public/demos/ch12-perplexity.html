直觉：困惑度 = "模型平均在多少个候选词里犹豫"。均匀乱猜 5 万个词 → PPL = 50000；每个 token 都百分百猜中 → PPL = 1。PPL 是概率的几何平均的倒数，所以一个极小的概率（比如 1e-5）就能把整体拉得很差。
